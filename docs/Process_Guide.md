# 📋 คู่มือขั้นตอนระบบ — หอกระจายข่าวชุมชน

---

## 🔐 ส่วนที่ 1 — การรีเซ็ตรหัสผ่านผู้ดูแลระบบ (Admin/Leader)

### ข้อกำหนดเบื้องต้น
> บัญชีผู้ดูแลระบบ **ต้องผูก LINE** (มี `line_user_id` ในระบบ) ก่อนจึงจะรีเซ็ตรหัสผ่านได้  
> OTP จะถูกส่งเข้า LINE OA ที่ผูกไว้เท่านั้น

---

### ขั้นตอนที่ 1 — เข้าหน้ารีเซ็ตรหัสผ่าน

1. ไปที่หน้าเข้าสู่ระบบ **`/admin/login`**
2. กดปุ่ม **"ลืมรหัสผ่าน?"** เพื่อไปหน้า `ForgotPasswordPage`

---

### ขั้นตอนที่ 2 — ขอรหัส OTP

1. กรอก **ชื่อผู้ใช้งาน (Username)** ในช่องที่กำหนด
2. กดปุ่ม **"ส่งรหัส OTP เข้า LINE"**

**สิ่งที่เกิดขึ้นในระบบ (Backend):**
- ระบบตรวจสอบว่า Username มีอยู่ในระบบหรือไม่ (แต่ตอบกลับข้อความเดียวกันทุกกรณี เพื่อป้องกันการ Enumerate Username)
- ตรวจสอบว่าบัญชีผูก LINE ไว้หรือยัง — ถ้ายังไม่ผูกจะ **ไม่ส่ง OTP**
- มี **Cooldown 60 วินาที** กันการกดขอ OTP ซ้ำรัว
- สร้าง **OTP 6 หลัก** (สุ่มแบบ Cryptographically Secure ด้วย `crypto.randomInt`)
- OTP **มีอายุ 10 นาที** และมีได้ **1 record ที่ active ต่อ 1 user** (record เก่าจะถูกยกเลิกอัตโนมัติ)
- ส่งข้อความเข้า LINE OA ของผู้ดูแลระบบทันที:
  ```
  🔐 [ระบบหอกระจายข่าวชุมชน]
  รหัส OTP สำหรับรีเซ็ตรหัสผ่านของบัญชี "username" คือ:

  👉 XXXXXX 👈

  (รหัสมีอายุการใช้งาน 10 นาที)
  หากท่านไม่ได้ทำรายการ โปรดละเว้นข้อความนี้
  ```

---

### ขั้นตอนที่ 3 — ยืนยัน OTP และตั้งรหัสผ่านใหม่

หลังส่ง OTP สำเร็จ ระบบจะเปลี่ยนไปหน้าฟอร์มที่ 2:

1. กรอก **รหัส OTP 6 หลัก** ที่ได้รับจาก LINE
2. กรอก **รหัสผ่านใหม่** (อย่างน้อย 6 ตัวอักษร) — กดปุ่ม 👁 เพื่อดู/ซ่อนรหัสผ่านได้
3. กรอก **ยืนยันรหัสผ่านใหม่** อีกครั้ง
4. กดปุ่ม **"ยืนยันการเปลี่ยนรหัสผ่าน"**

**สิ่งที่เกิดขึ้นในระบบ (Backend):**
- ตรวจสอบ OTP ว่าถูกต้องและยังไม่หมดอายุ
- **กรอก OTP ผิดได้สูงสุด 5 ครั้ง** — ครบแล้ว OTP จะถูกยกเลิกทันที (กัน Brute Force)
- Hash รหัสผ่านใหม่ด้วย `bcrypt` (10 Salt Rounds) ก่อนบันทึก (**ห้ามเก็บ Plain Text เด็ดขาด**)
- อัปเดต `password` ใน `tb_user`
- ทำเครื่องหมาย OTP ว่า `is_used = 1`
- ส่งข้อความยืนยันความปลอดภัยเข้า LINE:
  ```
  ✅ [ระบบหอกระจายข่าวชุมชน]
  รหัสผ่านสำหรับบัญชี "username" ได้รับการเปลี่ยนเรียบร้อยแล้ว

  หากท่านไม่ได้เป็นผู้ทำรายการ โปรดติดต่อผู้ดูแลระบบทันที
  ```

---

### ขั้นตอนที่ 4 — เข้าสู่ระบบด้วยรหัสผ่านใหม่

- ระบบแสดงหน้า **"เปลี่ยนรหัสผ่านสำเร็จ!"** พร้อมปุ่ม **"เข้าสู่ระบบทันที"**
- กดปุ่มเพื่อกลับไปหน้า Login และเข้าสู่ระบบด้วยรหัสผ่านใหม่ได้เลย

---

### Flowchart — รีเซ็ตรหัสผ่านแอดมิน

```
[Admin เปิดหน้า Login]
        │
        ▼
[กดลืมรหัสผ่าน → หน้า ForgotPasswordPage]
        │
        ▼
[กรอก Username → กด "ส่งรหัส OTP เข้า LINE"]
        │
        ├─ ❌ Username ไม่มีในระบบ → ตอบกลับข้อความกลางๆ (ไม่บอกว่าไม่มี)
        ├─ ❌ ไม่ได้ผูก LINE → ตอบกลับข้อความกลางๆ (ไม่บอก)
        ├─ ❌ เพิ่งขอ OTP ไปแล้ว (< 60 วิ) → แจ้ง Cooldown
        └─ ✅ สร้าง OTP → ส่ง LINE Push Message → ไปหน้า Step 2
                │
                ▼
        [กรอก OTP 6 หลัก + รหัสผ่านใหม่ → กดยืนยัน]
                │
                ├─ ❌ OTP ผิด (เหลือ < 5 ครั้ง) → แจ้งเตือน
                ├─ ❌ OTP ผิดครบ 5 ครั้ง → ถูก Invalid ต้องขอใหม่
                ├─ ❌ OTP หมดอายุ (> 10 นาที) → แจ้งขอใหม่
                └─ ✅ บันทึกรหัสผ่านใหม่ → ส่ง LINE แจ้งเตือน → หน้าสำเร็จ
                        │
                        ▼
                [กดเข้าสู่ระบบ → Login ด้วยรหัสผ่านใหม่]
```

## 👥 ส่วนที่ 2 — การลงทะเบียนลูกบ้าน (Villager Registration)

### ข้อกำหนดเบื้องต้น
> ลูกบ้านต้องเปิด LIFF **ผ่าน LINE App เท่านั้น** (ไม่สามารถเปิดผ่านเบราว์เซอร์ปกติได้)  
> ต้อง **เพิ่มเพื่อน LINE OA** ของหมู่บ้านก่อน จึงจะรับ OTP ได้

---

### ขั้นตอนที่ 1 — เปิด LIFF ผ่าน LINE

1. ลูกบ้านเปิด **LIFF Link** ที่ได้รับจากประกาศ/QR Code ของหมู่บ้าน
2. ระบบเรียก `liff.init()` และดึง **ID Token** จาก LINE อัตโนมัติ
3. ส่ง ID Token ไปตรวจสอบกับ Backend (`POST /api/villager/check`)

**Backend ตรวจสอบ:**
- Verify ID Token กับ LINE API (`api.line.me/oauth2/v2.1/verify`) เพื่อดึง `line_user_id` ที่น่าเชื่อถือ
- เช็คใน `tb_villager`:
  - **พบแล้ว** → เข้าสู่ระบบทันที (redirect ไปหน้า `/liff/home`)
  - **ไม่พบ** → แสดงฟอร์มลงทะเบียน

---

### ขั้นตอนที่ 2 — กรอกข้อมูลและขอรหัส OTP

1. กรอกข้อมูลในฟอร์ม:
   - **ชื่อจริง** และ **นามสกุล**
   - **บ้านเลขที่**
   - **ซอย/คุ้ม** (บังคับเลือก — ใช้กรองกลุ่มผู้รับข่าว)
   - ✅ ยอมรับ **นโยบาย PDPA** (บังคับ — ต้องยืนยันทั้งฝั่ง Frontend และ Backend)
2. กดปุ่ม **"ขอรหัสยืนยัน OTP"**

**สิ่งที่เกิดขึ้นในระบบ (Backend — `POST /api/villager/send-otp`):**
- Verify ID Token อีกครั้ง (ไม่เชื่อ lineUserId จาก Client ตรงๆ)
- ตรวจว่า LINE บัญชีนี้ยังไม่เคยลงทะเบียน
- มี **Cooldown 60 วินาที** กันการกดขอ OTP ซ้ำรัว
- มี **IP Rate Limit 10 ครั้ง / 15 นาที** (กัน Bot)
- สร้าง **OTP 6 หลัก** (CSPRNG) อายุ **5 นาที** พร้อม Atomic Lock (กัน Race Condition)
- ส่ง OTP เข้า LINE ของลูกบ้านทันที:
  ```
  🔐 [ระบบหอกระจายข่าวชุมชน]
  รหัสยืนยันการลงทะเบียนของคุณคือ:

  👉 XXXXXX 👈

  (รหัสมีอายุการใช้งาน 5 นาที)
  หากท่านไม่ได้ทำรายการ โปรดละเว้นข้อความนี้
  ```

---

### ขั้นตอนที่ 3 — ยืนยัน OTP และลงทะเบียน

1. เปิดแอป LINE เพื่อดูรหัส OTP
2. กลับมากรอก **รหัส OTP 6 หลัก** ในแบบฟอร์ม
3. กดปุ่ม **"ยืนยันและลงทะเบียน"**

**สิ่งที่เกิดขึ้นในระบบ (Backend — `POST /api/villager/register`):**
- Verify ID Token ซ้ำอีกรอบ (Security Best Practice)
- ตรวจสอบ `pdpaConsent === true` ฝั่ง Server (ไม่เชื่อ Client เพียงอย่างเดียว)
- ตรวจสอบ OTP:
  - **กรอกผิด** → แสดงจำนวนครั้งที่เหลือ
  - **ผิดครบ 5 ครั้ง** → OTP ถูกยกเลิก ต้องขอใหม่
  - **หมดอายุ (> 5 นาที)** → ต้องขอใหม่
- ตรวจสอบ ซอย/คุ้ม ว่ามีอยู่ใน `tb_zone` จริง
- บันทึกข้อมูลลูกบ้านลง **`tb_villager`**:
  - `line_user_id`, `display_name` (จาก LINE)
  - `first_name`, `last_name`, `house_number`, `zone_name`
  - `pdpa_consent_at` = เวลาฝั่ง Server (ป้องกันการปลอมแปลง)
  - `is_active = 1` (รับข่าวสารได้ทันที)
- ทำเครื่องหมาย OTP ว่า `is_used = 1`

---

### ขั้นตอนที่ 4 — เข้าใช้งานระบบ LIFF

- ระบบ redirect ไปหน้า **`/liff/home`** อัตโนมัติ
- ลูกบ้านรับข่าวสารผ่าน **Broadcast** จาก LINE OA ได้ทันที

---

### หมายเหตุพิเศษ — กรณีลูกบ้านบล็อก LINE OA

- เมื่อลูกบ้านกด **บล็อก** หรือ **ยกเลิกติดตาม** LINE OA
- LINE จะส่ง **Webhook Event `unfollow`** เข้าระบบ
- ระบบจะปรับ `is_active = 0` อัตโนมัติ → **หยุดส่งข่าว** ให้คนนั้นทันที (ตามกฎ PDPA)
- เมื่อลูกบ้าน **Re-follow** (ติดตาม OA ใหม่) → ระบบปรับ `is_active = 1` กลับ → **รับข่าวได้อีกครั้ง** โดยไม่ต้องลงทะเบียนใหม่

---

### Flowchart — ลงทะเบียนลูกบ้าน

```
[ลูกบ้านกดลิงก์ LIFF ใน LINE App]
        │
        ▼
[LIFF Init → ดึง ID Token → POST /api/villager/check]
        │
        ├─ ✅ พบในระบบแล้ว → redirect /liff/home (เข้าสู่ระบบทันที)
        │
        └─ 🆕 ไม่พบ → แสดงฟอร์มลงทะเบียน
                │
                ▼
        [กรอกข้อมูล + ยอมรับ PDPA + กดขอ OTP]
                │
                ├─ ❌ Cooldown < 60 วิ → แจ้งรอก่อน
                ├─ ❌ เพิ่งสมัครไปแล้ว → แจ้ง error
                └─ ✅ สร้าง OTP → ส่ง LINE Push → รอกรอก OTP
                        │
                        ▼
                [กรอก OTP 6 หลัก → กด "ยืนยันและลงทะเบียน"]
                        │
                        ├─ ❌ OTP ผิด → แจ้งเหลือกี่ครั้ง
                        ├─ ❌ ผิดครบ 5 ครั้ง → ต้องขอ OTP ใหม่
                        ├─ ❌ OTP หมดอายุ (> 5 นาที) → ต้องขอ OTP ใหม่
                        └─ ✅ บันทึกข้อมูล tb_villager → redirect /liff/home
```

## 🔑 สรุปความแตกต่างระหว่างสองกระบวนการ

| หัวข้อ | รีเซ็ตรหัสผ่านแอดมิน | ลงทะเบียนลูกบ้าน |
|--------|----------------------|------------------|
| ผู้ใช้งาน | Admin / Leader | ลูกบ้านทั่วไป |
| Auth ปลายทาง | Username + Password (JWT) | LINE LIFF (line_user_id) |
| ช่องทางรับ OTP | LINE ที่ผูกกับ Admin | LINE ของลูกบ้าน (บัญชีเดียวกับที่เปิด LIFF) |
| อายุ OTP | 10 นาที | 5 นาที |
| กรอกผิดได้สูงสุด | 5 ครั้ง | 5 ครั้ง |
| Cooldown ขอ OTP ซ้ำ | 60 วินาที | 60 วินาที |
| ข้อบังคับพิเศษ | ต้องผูก LINE ก่อน | ต้องยอมรับ PDPA |
| ผลหลังสำเร็จ | เข้า Admin Dashboard ด้วยรหัสใหม่ | เข้า LIFF Home รับข่าวได้ทันที |
